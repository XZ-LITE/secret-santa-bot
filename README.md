# 🎅 Secret Santa Telegram Bot

Телеграм-бот для проведения игры «Тайный Санта» в закрытом кругу (класс, студенческая группа, офис) с белым списком участников, защитой тайны дарения, ручным и автоматическим распределением, лимитами на изменения желаний и админ-панелью.

---

## 🚀 Особенности бота

- **Контроль доступа (Whitelist):** в бота могут зайти только пользователи из списка разрешённых Telegram ID.
- **Анкета участника:** выбор пола, ввод реального имени (ФИО), вишлист (до указанной суммы) и ссылки на товары (Wildberries, Ozon и др.).
- **Сохранение тайны:** каждый участник видит только пол и вишлист своего подопечного (без имени).
- **Лимиты правок:** изменить желание можно до 3 раз, пол — только 1 раз (до момента распределения).
- **Админ-панель:**
  - Автоматическое распределение (исключает дарение себе и тупики).
  - Ручное распределение (даритель → получатель) и смешанный режим.
  - Управление участниками (добавление, удаление, смена имени, сброс лимитов).
  - Выгрузка базы в **Excel** с автошириной колонок и создание бэкапов базы.
  - Массовые рассылки (всем, только зарегистрированным, либо выбранным пользователям с мультивыбором).
  - Планировщик напоминаний незарегистрированным перед дедлайном.

## ⚙️ Установка и локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/XZ-LITE/secret-santa-bot.git
   cd secret-santa-bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Linux/macOS:
   source venv/bin/activate
   # Windows:
   venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   Откройте файл `.env` и укажите ваш токен бота и Telegram ID администраторов:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_IDS=123456789,987654321
   INITIAL_ALLOWED_USERS=123456789,987654321,112233445
   GIFT_BUDGET=1000
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```

## 🌐 Быстрая установка на VPS (Ubuntu / Debian) в одну команду

На вашем сервере выполните:

```bash
git clone https://github.com/XZ-LITE/secret-santa-bot.git
cd secret-santa-bot
bash install.sh
```

### Что сделает скрипт установки:
1. Автоматически проверит и при необходимости установит **Docker** и **Docker Compose**.
2. В интерактивном диалоге запросит:
   - Токен Telegram-бота (от `@BotFather`);
   - Telegram ID администраторов (из `@userinfobot`);
   - Белый список участников (whitelist);
   - Бюджет подарка.
3. Сгенерирует безопасный файл `.env` и настроит права доступа.
4. Создаст в системе глобальную команду **`santa`**.
5. Соберёт Docker-образ и сразу запустит бота в фоновом режиме.

## 🛠️ Панель управления ботом (`santa`)

После установки вы можете управлять ботом прямо из терминала сервера из любой директории:

```bash
santa
```

Откроется удобное интерактивное меню:

```text
==========================================================
       🎅 ПАНЕЛЬ УПРАВЛЕНИЯ БОТОМ «ТАЙНЫЙ САНТА»          
==========================================================
  Статус: 🟢 РАБОТАЕТ

  1) 📊 Подробный статус и статистика (память, участники, дедлайн)
  2) ▶️  Запустить бота
  3) ⏹️  Остановить бота
  4) 🔄 Перезапустить бота
  5) 📜 Просмотр логов (live logs)
  6) ⚙️  Редактировать настройки (.env)
  7) 💾 Создать резервную копию базы данных (бэкап)
  8) 📂 Восстановить базу данных из бэкапа
  9) 🚀 Обновить бота с GitHub (pull & rebuild)
  0) 🚪 Выход
```

### Быстрые команды без входа в меню:
- `santa status` — проверить статус контейнера, нагрузку CPU/RAM и статистику участников.
- `santa logs` — просмотр логов в реальном времени.
- `santa restart` — перезапуск бота.
- `santa stop` — остановка бота.
- `santa start` — запуск бота.
- `santa backup` — создать бэкап базы данных прямо сейчас в `backups/`.
- `santa restore` — интерактивно выбрать и восстановить нужный бэкап.
- `santa env` — быстро отредактировать `.env` в nano.
- `santa update` — подтянуть свежий код из GitHub (`git pull`) и пересобрать контейнер.

Все данные и бэкапы надёжно сохраняются на хосте в папках `./data/` и `./backups/`.
